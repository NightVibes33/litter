Quick troubleshooting

Server not discovered

Make sure the device and target server are on the same network if you are using local discovery. Check Wi-Fi, VPN state, subnet differences, and firewall rules that may block discovery traffic.

Remote connection fails

Verify the SSH host, port, username, and network path. If the host was recently restarted, reconnect instead of relying on a stale session state.

Model picker looks wrong

Disconnect and reconnect the runtime, then reopen the model picker. If the issue only affects one backend, include the runtime type and whether the list is empty, stale, or partially loaded.

Voice session closes

Check microphone permission in iOS Settings and retry on a stable network. Note whether the failure happens before recording begins, during streaming, or after the session connects.

Project browser is stuck

Reconnect the runtime and retry the directory or project picker. If it only happens remotely, include the folder path and whether the runtime rejected a file-list or picker command.

TestFlight build will not install

Verify that you are on the newest available TestFlight build. If an older beta state is stuck on the device, remove the app, reinstall the latest build, and include the affected build number in your report.

Privacy and data deletion

Alley Cãt is designed around direct connections to runtimes and systems you control. For local data removal, delete the app from your device. If you saved connections, credentials, or tokens inside the app, remove them there first when possible.

For privacy questions, contact NightVibes33@proton.me.

Expected behavior

Connection quality depends on the runtime you use, the local or remote network path, SSH availability, and host responsiveness. A runtime outage can look like an app bug, so include runtime details when reporting issues.

Supported builds are distributed through approved beta and public release channels for compatible devices.
